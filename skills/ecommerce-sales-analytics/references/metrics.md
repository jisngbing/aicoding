# 指标定义和字段映射

## 默认指标

| 指标 | 默认定义 | 注意事项 |
| --- | --- | --- |
| 实收销售额 | 统计范围内成功支付的商品行实收金额之和 | 已扣订单优惠分摊；若包含运费/税必须说明 |
| 退款额（订单归属） | 所选支付订单截至数据导出时累计的商品行退款金额 | 退款归原支付日期，会改变历史净额；不等于当日现金退款 |
| 净销售额 | 实收销售额 − 同口径退款额 | 不等于利润或财务确认收入 |
| 支付订单数 | 成功支付订单的 distinct order_id | 含后来退款订单；不能把商品行数当订单数 |
| 购买人数 | 成功支付订单的 distinct buyer_id | 必须使用稳定脱敏ID；匿名买家不能擅自算唯一用户 |
| 实收客单价 | 实收销售额 / 支付订单数 | 不是净额客单价；无订单时为不可计算 |
| 商品销量 | 成功支付的商品件数 | 含后来退款商品；没有退货数量不能推算净销量 |
| 金额退款率 | 订单归属退款额 / 实收销售额 | 分子分母必须同一批订单；0分母不可计算 |
| 环比 | (本期值 − 上期值) / 上期值 | 上期0时无可比基数；等长周期并说明未结束周期 |

GMV 的定义随业务变化，可能是下单总额，也可能是支付总额；未经确认不把实收额直接标成 GMV。
转化率需要会话/访客等分母，毛利需要成本，ROI 需要投放成本和归因规则，缺数据则不计算。

## CSV 脚本的输入契约

UTF-8（允许 BOM）CSV，每行是一个订单商品行。所有金额为该行的金额，最多两位小数，不带千分位和币种符号；金额不能为负、退款不得超过实收。

| 列 | 含义 |
| --- | --- |
| line_id | 全文件唯一商品行ID；重复即报错，不静默去重 |
| order_id | 订单ID；同订单所有行必须同一支付日、买家与币种 |
| paid_date | 业务时区支付日期 YYYY-MM-DD；未支付行可空 |
| buyer_id | 稳定的匿名买家ID，不用姓名/电话 |
| product_id / product_name | 商品ID/展示名，聚合按ID |
| quantity | 正整数支付件数 |
| paid_amount | 分摊优惠后的本行实收，不得重复填写整单金额 |
| refund_amount | 本行累计已完成退款，未退款填0 |
| status | paid / completed / partially_refunded / refunded / unpaid / cancelled |
| currency | 单币种代码，如 CNY；脚本拒绝将其他币种混入所选范围 |

筛选区间包含起止日期；日趋势补齐区间内无销售日期。脚本统计的是输入快照的订单归属退款，不支持历史时点恢复、退款发生日现金流、跨币种折算和真实数据库直接连接。

## 关联数据防重

订单与支付记录、退款记录都有一对多关系时，不要直接三表连接后 SUM。先把成功支付按订单（或商品行）聚合，把成功退款单独聚合，再按相同粒度连接；退款不能同时在支付表和退款表重复扣除。

订单级优惠需分摊时，明确按商品原价或其他业务权重分配，保留到分，末行分配舍入差额，确保行金额之和精确等于订单金额。无法可靠分摊时可交付订单维度统计，并注明暂不支持商品金额排行。
